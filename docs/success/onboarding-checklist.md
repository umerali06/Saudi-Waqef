# Onboarding Checklist

## Company setup
- [ ] Create company profile.
- [ ] Configure fiscal year and VAT settings.
- [ ] Upload logo and document templates.

## Accounting setup
- [ ] Confirm chart of accounts.
- [ ] Add tax categories.
- [ ] Set default payment terms.

## HR setup
- [ ] Add departments and positions.
- [ ] Import employees.
- [ ] Configure payroll settings.

## First transactions
- [ ] Create first sales invoice.
- [ ] Record first expense.
- [ ] Run first payroll draft.
