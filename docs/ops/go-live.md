# Go-live & Support

## Go-live Steps
1. Freeze changes and run a full regression.
2. Create a final Firestore backup.
3. Deploy to production.
4. Run smoke checks:
   - Login
   - Create invoice & bill
   - VAT summary
   - Payroll run
   - Support ticket submission
5. Open access for users.

## Support Plan
- Support hours: 9am–6pm KSA.
- Critical incidents: 1-hour response, 4-hour resolution target.
- Non-critical: 24-hour response.

## Escalation
- Tier 1: Support agent
- Tier 2: Senior engineer
- Tier 3: Product owner

## Feedback Collection
- Weekly review of top 10 issues.
- Monthly product backlog grooming.
