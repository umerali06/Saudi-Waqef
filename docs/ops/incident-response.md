# Incident Response Plan

## Severity levels
- SEV1: Full outage or data loss risk.
- SEV2: Major feature degradation.
- SEV3: Minor disruption or UI issues.

## Escalation matrix
- On-call engineer → Engineering lead → Product owner → Legal/Compliance (if required).

## Communication templates
- Internal: describe impact, systems affected, ETA for next update.
- External: acknowledge issue, outline impact, provide next update time.

## Post-incident
1) Root cause analysis within 48 hours.
2) Corrective actions tracked as tickets.
3) Add regression tests or monitoring alerts.
